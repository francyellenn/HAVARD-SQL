## 🗃️ O que é este Repositório?

Este repositório é dedicado ao **CS50 SQL: Introduction to Databases with SQL** de **Harvard**. 

Aqui é onde aprendi a conversar com bancos de dados relacionais, criar esquemas eficientes, relacionar dados complexos (tipo o gigante banco de dados de filmes do IMDb) e, o mais importante de tudo: **aprender a nunca dar um `DELETE` sem a cláusula `WHERE`**.

## ⚠️ As Leis Sagradas do SQL

1. **Jamais**, sob hipótese alguma, rode `DELETE FROM usuarios;` na sexta-feira às 17h.
2. Um `LEFT JOIN` mal feito pode trazer a internet inteira para a sua tela.
3. Se a consulta demorou 10 minutos pra rodar, faltou criar um **Índice**.
